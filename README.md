# 📊 BMI Analysis Dashboard

An end-to-end data analysis project that analyzes Body Mass Index (BMI) data across age groups, countries, gender, and activity levels using Python and Power BI.

---

## 🔧 Tools & Technologies
- Python (random, csv)
- Excel (data validation & age grouping)
- Power BI (DAX, cards, slicers, charts)
- GitHub

---

## 📂 Project Workflow
1. Generated realistic synthetic BMI data using Python
2. Cleaned and enriched data in Excel
3. Built an interactive Power BI dashboard
4. Added slicers and KPIs for insights

---

## 📈 Dashboard Insights
- Average BMI by Country
- Average BMI by Age Group
- BMI trend by Activity Level
- Percentage of Overweight & Obese individuals
- Gender, Age Group & Status filters

---


## 📌 Key Learnings
- Data generation using Python
- Data modeling & measures in Power BI
- KPI design & dashboard storytelling
- End-to-end analytics workflow
